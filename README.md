# CSE3130-OOP2-Project

## Overview
The program is meant to recreate the famous computer game "Brick Breaker" using Pygame. The game is for one player where they control a paddle to hit the ball to prevent it from falling to the bottom of the screen. The ball bounces around to destroy all the bricks to clear the level. 

## How to Run the Program
To start the game, run main.py and the game window will pop up. If you want to end the game, press the red "X" in the top right corner of the window to close it.
